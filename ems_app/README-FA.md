# همراه اورژانس ۱۱۵ — نسخه ۱.۲.۰ با اشتراک کافه‌بازار

## قابلیت‌های این نسخه
- فهرست ۶۱ عنوان پروتکل و PDF اصلی ۱۱۹ صفحه‌ای حفظ شده است.
- ۳۰ عنوان اول فهرست رایگان هستند.
- ۳۱ عنوان بعدی با اشتراک فعال کافه‌بازار باز می‌شوند.
- قفل فقط در فهرست نیست: باز کردن PDF، رفتن به صفحه بعد، نوار انتخاب صفحه و رفتن مستقیم به صفحات ۶۲ تا ۱۱۹ نیز در لایه اندروید کنترل می‌شود.
- خرید اشتراک با Poolakey نسخه ۲.۲.۰ و بازیابی وضعیت از `getSubscribedProducts` انجام می‌شود.
- شناسه محصول: `115_EMS_guide`
- کلید عمومی RSA ارائه‌شده توسط صاحب برنامه در `MainActivity.kt` قرار گرفته است.
- آیکن، فایل PDF، یادداشت‌ها، علاقه‌مندی‌ها، نشانه‌گذاری و ظاهر اصلی پروژه حفظ شده‌اند.

## تنظیم ضروری در پنل کافه‌بازار
قبل از انتشار، در پنل توسعه‌دهندگان کافه‌بازار بررسی کنید:
1. شناسه اشتراک دقیقاً `115_EMS_guide` باشد.
2. محصول از نوع «اشتراک» باشد، نه خرید یک‌باره.
3. مدت اشتراک در پنل روی ۳۶۵ روز تنظیم و محصول فعال/قابل فروش باشد.
4. محصول برای همین شناسه برنامه (`ir.ems115.companion`) تعریف شده باشد.
5. کلید عمومی داخل سورس دقیقاً با کلید نمایش‌داده‌شده در پنل همین برنامه تطبیق داده شود.

مدت ۳۶۵ روز از تنظیمات محصول در پنل بازار می‌آید؛ کد برنامه مدت اشتراک را تعیین نمی‌کند. برنامه فقط وضعیت اشتراک را از سرویس بازار می‌پرسد.

## ساخت
- JDK 17
- Android SDK Platform 35 و Build Tools 35.0.0
- Gradle 8.9
- وابستگی Poolakey از JitPack دریافت می‌شود؛ برای build اتصال اینترنت لازم است.
- دستور ساخت APK آزمایشی: `gradle --no-daemon assembleDebug`

## آزمون پرداخت
خرید واقعی فقط روی دستگاهی قابل آزمون است که برنامه کافه‌بازار نصب و به‌روز داشته باشد و نسخه برنامه از مسیر/حساب مناسب برای آزمون پرداخت در بازار در دسترس باشد. APK دیباگ برای انتشار در بازار مناسب نیست. برای انتشار، APK باید با همان کلید امضای نسخه قبلی برنامه امضا شود.

## نکته امنیتی
در این نسخه، اعتبارسنجی محلی امضای خرید با کلید عمومی بازار توسط Poolakey فعال است. برای سامانه‌های حساس و جلوگیری قوی‌تر از دستکاری کلاینت، اعتبارسنجی سمت سرور با API توسعه‌دهندگان بازار توصیه می‌شود؛ این پروژه در حال حاضر سرور اعتبارسنجی اختصاصی ندارد.


## ساختار سورس در مخزن GitHub
فایل‌های متنی و کد برنامه در مسیر `ems_app/` به‌صورت فایل‌های مستقل ثبت شده‌اند تا مستقیماً در GitHub قابل مشاهده و بررسی باشند. فایل ZIP قدیمی در ریشه مخزن حذف یا جایگزین نشده است؛ گردش‌کار ساخت فقط فایل‌های باینری PDF و آیکن‌ها را از آن بازیابی می‌کند و سورس اصلی را از فایل‌های مستقل همین مخزن می‌سازد.
